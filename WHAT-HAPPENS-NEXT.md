# What Happens Next? - Complete Teacher Workflow

## 🎯 **You're Here: Grade Management Page**

You've successfully landed on the Grade Management page. Here's exactly what happens next:

---

## 📋 **STEP 1: Select Your Options**

From the dropdowns, select:

### **Class Dropdown**
- Choose the class you teach (e.g., "Primary 1")
- Available: All classes from Nursery to Year 9

### **Session Dropdown** 
- Select academic year (e.g., "2024/2025")
- Current and future sessions available

### **Term Dropdown**
- Choose term (e.g., "Term 1")
- Currently: "Term 1" (can add more terms)

### **Subject Dropdown**
- Select subject you're grading (e.g., "Mathematics")
- 29 subjects available including English, Science, etc.

---

## 🔄 **STEP 2: Magic Happens Automatically**

Once you select all dropdowns, the system:

✅ **Fetches Students** - Loads all students in your selected class  
✅ **Creates Table** - Generates grade entry table automatically  
✅ **Displays Names** - Shows student names and admission numbers  
✅ **Prepares Fields** - Creates input fields for scores  

---

## 📝 **STEP 3: Enter Grades**

You'll see a table like this:

```
┌─────────────────────────────────────────────────────────────┐
│ Admission No   Student Name        1st  2nd  4th  Average   │
├─────────────────────────────────────────────────────────────┤
│ DPS2026012      Maryam Amin        [__] [__] [__]   ---    │
│ DPS2026011      David Oloruntola   [__] [__] [__]   ---    │
└─────────────────────────────────────────────────────────────┘
```

### **Enter Scores:**
- **1st Score**: First assessment (0-100)
- **2nd Score**: Second assessment (0-100)  
- **4th Score**: Final assessment (0-100)
- **Average**: Calculated automatically!

### **Example Entry:**
```
DPS2026012  Maryam Amin        85   88   90   87.7%
DPS2026011  David Oloruntola   92   85   88   88.3%
```

---

## 💾 **STEP 4: Save Grades**

Click the **"Save Grades"** button and the system:

🔐 **Authenticates** - Confirms you're logged in as teacher  
✅ **Validates** - Checks all scores are valid (0-100)  
💾 **Saves** - Stores grades in database securely  
🎉 **Confirms** - Shows "Grades saved successfully!" message  

---

## 🔄 **STEP 5: What You Can Do Next**

After saving, you have options:

### **Option 1: Grade Another Subject**
- Change "Subject" dropdown to "English"
- Same students appear, empty score fields
- Enter English grades for same class

### **Option 2: Grade Another Class** 
- Change "Class" dropdown to "Primary 2"
- Different students appear
- Enter Mathematics grades for new class

### **Option 3: View Results**
- Click "View Results" in dashboard
- See how students will view their grades
- Verify everything looks correct

### **Option 4: Other Tools**
- Return to dashboard
- Access calendar, notifications, student management

---

## 👨‍🎓 **STEP 6: Student Experience**

When students log in:

1. **Login** with admission number
2. **Go to Results** page  
3. **Select** same class/session/term
4. **Enter** admission number
5. **See** comprehensive results including your grades!
