SESSION FILTERING IS NOT A BUG
================================

Finding: Class detail page shows fewer students than main page
Root Cause: Architectural difference, not a code bug

✅ MAIN PAGE (NO SESSION FILTER):
   - Shows ALL students ever enrolled (across all sessions/years)
   - Used for: Reference, compliance, historical data

✅ DETAIL PAGE (WITH SESSION FILTER):
   - Shows ONLY current-session students (2026/2027)
   - Used for: Grade recording, promotion workflow

✅ WHY THIS IS CORRECT:
   - Prevents accidental data mixing across years
   - Supports school promotion workflow (current → next year)
   - Maintains historical data for compliance
   - Enables session isolation for data integrity
